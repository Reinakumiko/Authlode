## 📂 后端 (backend/)

```
backend/
├── 📄 package.json                 # NestJS 11 + @nestjs/axios + Prisma + Jest
├── 📁 prisma/
│   ├── 📄 schema.prisma            # 扩展库模型（6 个，均无 tenantId — 批次 1 迁移）
│   │                               #   UserInvitation / AuditLog / UserExtend
│   │                               #   BatchOperation / UserNotification / StatisticsCache
│   └── 📁 migrations/
├── 📁 scripts/                     # 工具脚本
├── 📁 test/                        # e2e 测试
└── 📁 src/
    ├── 📄 main.ts                  # 入口（端口 3001）
    ├── 📄 app.module.ts            # 根模块（无 Auth — 批次 1 补）
    │
    ├── 📁 config/                 # 配置系统
    │   ├── 📄 config.service.ts
    │   └── 📁 dto/                # app/database/env/jwt/logto/mail/redis 配置 DTO
    │
    ├── 📁 logto/                  # ★ Logto 集成（批次 1 改造为 iam/logto-adapter）
    │   ├── 📄 logto.service.ts    # 743 行 Management API 封装
    │   │                          # ⚠️ F1: 静态 API key 假设错误，需 M2M token 交换
    │   ├── 📄 logto.controller.ts
    │   └── 📁 interfaces/          # User/Organization/Role/Application 类型
    │
    ├── 📁 prisma/                 # PrismaService
    ├── 📁 common/repositories/     # BaseRepository（批次 1 加租户过滤钩子）
    │
    ├── 📁 users/                   # 用户 controller（真实 Logto 调用）
    ├── 📁 organizations/           # 组织 controller（真实调用；语义待改为租户内组织树）
    ├── 📁 roles/                   # 角色 controller（真实调用，仅实例级）
    ├── 📁 applications/           # 应用 controller（真实调用）
    ├── 📁 settings/                # 设置 controller（纯配置读取）
    ├── 📁 statistics/              # 统计（混合 Logto + 扩展库）
    │
    ├── 📁 invitations/            # 邀请（service 为空壳 — 批次 3 实现）
    │   └── 📁 repositories/
    ├── 📁 audit-logs/             # 审计（service + repository 已有）
    └── 📁 user-extends/           # 用户扩展信息（repository 已有）
```

**批次 1 计划新增**（见 [SSO平台实施方案.md](SSO平台实施方案.md) 1.1）：
