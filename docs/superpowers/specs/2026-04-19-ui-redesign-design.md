# Logto Manager 界面重设计方案

**日期**: 2026-04-19 (创建) / 2026-04-22 (更新)
**状态**: 进行中

## 设计方向

Arc/Raycast 风格的彩色毛玻璃设计。浅色系、多层渐变、半透明磨砂质感、精致有活力。

## 核心视觉要素

### 1. 配色
- **主色**: 蓝紫/蓝绿/青色冷色调系列（#6366f1, #8b5cf6, #3b82f6, #14b8a6, #06b6d4）
- **辅助色**: 可用多彩混搭，不同模块可用不同色调
- **避免**: 暖橙金色、冷蓝银灰色
- **文字色**: 深色（#1d1d1f, #334155）在浅色毛玻璃卡片上

### 2. 背景
- 柔和渐变底色（蓝→紫→绿极淡过渡）
- 非纯白、非浅灰、非深色

### 3. 毛玻璃效果
- 卡片、侧边栏使用 `backdrop-filter: blur(20-40px)`
- 半透明白色背景（rgba(255,255,255,0.4-0.65)）
- 微弱白色边框（rgba(255,255,255,0.5-0.7)）
- 柔和阴影（多层 box-shadow）

### 4. 侧边栏
- 带色彩底色渐变（蓝→紫→绿淡色渐变）+ 毛玻璃
- 彩色 Logo 图标
- 分组标题可带主题色（如紫色）
- 激活项: 白色半透明背景 + 主题色文字 + 微弱边框
- 不要纯白/纯透明/纯暗色

### 5. 卡片样式
- 支持多种: 圆点指示器、环形进度、色彩底色（不用渐变图标框）
- 圆角: 6-10px
- 数据展示用粗进度条（18-24px 高度）+ 渐变填充 + 内嵌百分比
- 悬停: 轻微上浮 + 增强阴影

### 6. 图标
- SVG 线条图标（Lucide/Heroicons 风格），统一 stroke 1.5px
- 可搭配淡色圆角底色或裸用
- 不要 emoji、不要渐变方块图标框
- 图标风格必须一致（同一图标集，同一 stroke 宽度）

### 7. 间距与排版
- 舒适的留白（不过度紧凑）
- 大数字用 700 粗体 + 紧字距（letter-spacing: -0.02em）
- 标签/描述文字用 500 字重 + 中灰色

## 设计关键词

渐变 / 毛玻璃 / 磨砂 / 半透明 / 层次感 / 活力 / 精致 / 现代

## 不要的风格

深色暗色主题 / 纯黑白极简 / 暖白纸质感 / 标准管理后台 / Vercel 式零色彩

## Dashboard 各板块设计方案

> 状态标记: ✅ 已确认 | 🔧 设计中 | ⏳ 待设计

### ✅ 1. 指标卡片
**选定方案**: D — 大数字在左，标签+变化趋势在右，底部粗进度条

布局特点:
- 左侧大数字 (700-800 字重, 紧字距)
- 右侧标签 + 变化趋势指示
- 底部 18-24px 高粗进度条 + 渐变填充 + 内嵌百分比
- 卡片间 grid 布局, gap: 12px

展示指标: 总用户数 / 组织数量 / 应用数量 / 活跃会话数 / 待处理邀请数

Mockup 文件: `.superpowers/brainstorm/.../content/metric-cards.html` (方案 D)

### ✅ 2. 硬件监控 (含服务状态)
**选定方案**: 三栏布局 — 服务状态 | CPU+内存折线 | 硬盘饼图

布局特点:
- **左栏 (180px)**: 服务状态卡片
  - 标题 14px 700, 列表项 13px, 标题与列表间距 18px
  - 每项: 状态点 + 服务名 + 状态值
  - 展示: Logto / 数据库 / 缓存状态 + 运行时间

- **中栏 (1fr, 宽度可调)**: CPU + 内存折线图上下叠放
  - 每个小卡片: 圆点色标 + 标题 (13px) + 右侧大数字 (17px 800)
  - 折线图 36px 高, 贝塞尔曲线 + 渐变填充 + 尾端圆点指示器
  - CPU 色: #6366f1, 内存色: #8b5cf6
  - 卡片背景: 半透明白色 + backdrop-filter blur

- **右栏 (180px)**: 硬盘环形饼图
  - SVG 环形图, 渐变 stroke (#14b8a6 → #06b6d4)
  - 中心: 百分比数字 (20px 800) + "已使用"标签
  - 底部: 容量文字 (190 / 500 GB)

整体: max-width ~700px, gap: 12px

Mockup 文件: `.superpowers/brainstorm/.../content/hardware-monitor.html` (方案 A)

### ❌ 3. 系统负载趋势图
**说明**: 已合并到硬件监控区的 CPU/内存折线图中，不单独设板块

### ✅ 4. 动态告警
**选定方案**: D（圆形图标底色）和 E（极简色点）方向

方案 D — 圆形图标底色:
- 图标用圆形彩色底色，与硬件监控风格统一
- 正常: 绿色底 ✓ | 警告: 橙色底 ! | 严重: 红色底 ✕
- 标题 13px 600 + 描述 12px + 时间 11px

方案 E — 极简色点:
- 与活动流风格统一，色点 + 文字 + 级别标签
- 严重时显示额外详情行（如 IP、用户名）
- 级别标签: 正常(绿)/警告(橙)/严重(红) 徽章

条件显示: 正常时可显示一条"系统正常"或完全不占位

Mockup 文件: `.superpowers/brainstorm/.../content/remaining-v2.html` (方案 D/E)

### ✅ 5. 快捷入口
**选定方案**: W — 色点指示 + SVG 图标 + 数字 + 渐变条

布局特点:
- 5 列 grid，gap: 10px，max-width: 700px
- 每个卡片:
  - 顶部: 发光色点 (6px, box-shadow glow) + 英文小标签 (10px 600 uppercase)
  - 中部: SVG 线条图标 (stroke 1.5px)
  - 下部: 大数字 (20px 800) + 单位 (10px)
  - 底部: 渐变条 (3px, hover 时 opacity 0.5→1)
- 卡片: 毛玻璃 (blur 24px) + 圆角 16px + min-height 120px
- 交互动效: hover 上浮 2px + 阴影增强 / active 缩放 0.98 (80ms)

颜色分配: 用户 #6366f1 / 邀请 #8b5cf6 / 组织 #3b82f6 / 角色 #14b8a6 / 应用 #ec4899

设计规范 (ui-ux-pro-max): 统一 stroke 1.5px、8dp 间距节奏、touch target ≥44px、200ms ease

Mockup 文件: `.superpowers/brainstorm/.../content/quick-actions-v7.html` (方案 W)

### ✅ 6. 最近活动流
**选定方案**: 色点列表

布局特点:
- 玻璃卡片内列表
- 每项: 彩色圆点 (6px) + 文字描述（粗体人名/操作） + 右侧时间
- 分隔线: 0.5px rgba(0,0,0,0.04)
- 不同操作类型用不同颜色圆点区分

### ✅ 7. 底部状态栏
**选定方案**: 简洁一行

布局特点:
- 玻璃条，padding 10px 16px
- 左: 绿色状态点 + "系统正常运行中"
- 右: 最后更新时间 + 版本号
- 字号 11px, 颜色 #aeaeb2

### ⏳ 8. 整体页面布局
**说明**: 以上各板块的排列顺序和整体 grid 布局
