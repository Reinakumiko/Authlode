🎨 Authlode UI 风格方案

3 个不同方向的 Dashboard 设计预览，选择你喜欢的风格

方案 A — Soft Glass

推荐 · 毛玻璃 + 渐变光球

半透明卡片 + backdrop-blur + 柔和渐变光斑背景 + 大圆角 + 渐变进度条。精致、现代、有层次感。

方案 C — Bento Clean

克制 · Apple 风格 + 干净留白

浅灰底 + 白色圆角卡片 + 极简阴影 + 大量留白 + 精致排版。最清爽、最专业。

方案 D — Warm Clay

温暖 · 陶土色 + 有机质感

暖色系配色 + 圆润造型 + 柔和阴影 + 自然渐变。亲切、舒适、不冰冷。
