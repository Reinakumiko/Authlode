## 最终建议保留清单（按优先级）

### 必须有
1. 总用户数 / 组织数量 / 应用数量 — 核心指标
2. 活跃会话数 — 实时负载
3. 待处理邀请数 — 可操作项
4. Logto 服务状态 + 数据库状态 — 系统健康
5. CPU / 内存 / 硬盘使用率 — 系统监控
6. 系统运行时间
7. 系统负载趋势图（原活跃会话趋势）— 唯一的主图表
8. 最近操作记录 — 活动流
9. 5 个快捷入口 — 用户/邀请/组织/角色/应用

10. 异常登录告警
11. 性能告警
12. 登录失败次数
