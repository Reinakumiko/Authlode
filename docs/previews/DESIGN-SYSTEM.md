# Authlode UI 设计系统 — Soft Glass

> 基于 Style-A（Soft Glass）方案提炼，作为整个框架 UI 的统一设计方向。

---

## 1. 设计理念

**Soft Glass（柔雾玻璃）** 风格——轻盈、通透、有呼吸感。

核心关键词：
- **毛玻璃（Glassmorphism）**：`backdrop-filter: blur()` + 半透明白色背景
- **渐变光球（Orbs）**：背景用 radial-gradient 营造柔和的光影层次
- **大圆角**：统一 16–20px，传递友好与现代感
- **轻交互**：hover 微浮起 + 阴影加深，过渡 0.2–0.3s
- **浅色主题**：白底 + 淡蓝紫绿渐变背景，不用深色

## 2. 色彩系统

### 2.1 主色（Brand）

| Token | 色值 | 用途 |
|-------|------|------|
| `--indigo` | `#6366f1` | 主品牌色，按钮、导航高亮、图标 |
| `--purple` | `#8b5cf6` | 辅助色，渐变搭配、次级强调 |
| `--teal` | `#14b8a6` | 点缀色，成功状态、渐变尾端 |

### 2.2 文字色（Text）

| Token | 色值 | 用途 |
|-------|------|------|
| `--text` | `#1e293b` | 主文字（标题、数值） |
| `--text2` | `#64748b` | 次要文字（标签、描述） |
| `--text3` | `#94a3b8` | 辅助文字（时间戳、辅助信息） |

### 2.3 功能色

| 语义 | 色值 | 用途 |
|------|------|------|
| 成功 | `#22c55e` | 状态点、运行中 |
| 成功（文字） | `#16a34a` | 变化率 ↑ |
| 危险 | `#dc2626` | 变化率 ↓ |
| 警告 | `#f59e0b` | 告警日志 |

### 2.4 背景渐变

```
body background: linear-gradient(135deg, #f0f4ff, #f5f0ff 50%, #f0faf5)
```

淡蓝 → 淡紫 → 淡绿，135° 对角渐变。

### 2.5 光球（Orbs）

三个固定定位的 radial-gradient 圆形，营造背景光影：

| 光球 | 尺寸 | 颜色 | 位置 |
|------|------|------|------|
| orb1 | 600×600px | `rgba(99,102,241,0.12)` | 左上 |
| orb2 | 500×500px | `rgba(139,92,246,0.1)` | 右下 |
| orb3 | 400×400px | `rgba(20,184,166,0.1)` | 中部偏左 |

## 3. 字体系统

### 3.1 字体家族

| 用途 | 字体 | 备选 |
|------|------|------|
| **正文字体** | `'DM Sans'` | `sans-serif` |
| **数字/标题字体** | `'Space Grotesk'` | `sans-serif` |

> Space Grotesk 用于需要「数字感」的场景：大标题、数值、监控标题。

### 3.2 字号梯度

| 级别 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 28px | 800 | 页面主标题（h1） |
| Metric | 28px | 800 | 指标卡片大数字 |
| Mon-val | 28px | — (继承) | 监控数值 |
| Section | 16px | 700 | 区块标题 |
| Mon-title | 14px | 700 | 监控卡片标题 |
| Body | 14px | — | 正文、按钮 |
| Body-sm | 13px | 500/600 | 标签、列表项 |
| Caption | 12px | — | 变化率、时间戳 |
| Tiny | 11px | — | 角色、辅助文字 |

### 3.3 letter-spacing

数字类大标题统一使用 `letter-spacing: -0.02em`，让大号数字更紧凑。

## 7. 毛玻璃（Glassmorphism）规范

### 7.1 标准毛玻璃卡片

```css
background: rgba(255,255,255,0.55);
backdrop-filter: blur(16px);
-webkit-backdrop-filter: blur(16px);
border: 1px solid rgba(255,255,255,0.7);
```

适用：所有内容卡片（metric-card、mon-card、activity、qa-card）

### 7.2 侧边栏毛玻璃

```css
background: rgba(255,255,255,0.6);
backdrop-filter: blur(20px);
-webkit-backdrop-filter: blur(20px);
border-right: 1px solid rgba(255,255,255,0.8);
```

比内容卡片多 4px blur，白色略多一点，因为侧边栏是固定定位。

### 7.3 用户区域

```css
background: rgba(255,255,255,0.5);
border: 1px solid rgba(255,255,255,0.7);
```

无 blur，纯半透明白。

- 右侧：曲线图，`flex: 1` 自适应，高度 80px

## 10. 组件规范

### 10.1 指标卡片（Metric Card）

```
┌──────────────────────────────┐
│  总用户                 [📊] │  ← label 左上 + icon 右上
│  2,847           ↑ 12.5%     │  ← 大数字 + 变化率 badge
│  ████████████░░░░░░░         │  ← 进度条（全宽）
└──────────────────────────────┘
```

- 左右视觉分配：左侧数字 + 标签，右侧 icon + 趋势
- 进度条位于底部，高度 6px，圆角 3px
- 每个卡片对应不同的渐变色条

### 10.2 监控卡片（Monitoring Card）

**服务状态**（左列）：
- 标题在上，服务列表在中间，运行时间在底部
- `justify-content: space-between` 均匀分布

**CPU + 内存**（中列，合并卡）：
- 卡片内部上下两行
- 每行：左侧 icon + 标题 + 数值，右侧自适应曲线图
- 曲线图 stroke-width: 1.5，透明渐变填充

**磁盘使用率**（右列）：
- 居中布局：标题 + 环形图 + 说明文字
- 环形图 120×120px，stroke-width: 12

### 10.3 快捷操作卡片（Quick Action Card）

```
┌──────────────┐
│    [Icon]    │  ← 彩色背景圆角方块
│   用户管理   │  ← 标题
│  2,847 用户  │  ← 辅助计数
└──────────────┘
```

### 10.4 活动/日志列表（Activity List）

- 双栏布局：最近活动 + 系统日志
- 每条记录：彩色圆点 + 文字内容 + 时间戳
- 分割线：`1px solid rgba(0,0,0,0.04)`
- strong 标签用于强调人名/实体名

### 10.5 按钮

- 主按钮：渐变背景 `linear-gradient(135deg, indigo, purple)`，白色文字
- 圆角 12px，padding 10px 20px
- 左侧 icon + 文字

### 10.6 导航项

- 左侧 3px 透明边框，active 时变为 indigo
- Active 状态：白色背景 + indigo 文字 + 微阴影
- 图标 20×20px

## 11. 图表规范

### 11.1 曲线图（SVG）

```css
stroke-width: 1.5;          /* 细线 */
stroke-linecap: round;       /* 圆角端点 */
```

- 渐变线条 + 半透明渐变填充
- viewBox: `0 0 200 40`
- 渐变填充 opacity: 0.15
- 使用 `preserveAspectRatio="none"` 铺满容器

### 11.2 环形图（SVG）

- 大小：120×120px
- stroke-width: 12
- 底色：`rgba(0,0,0,0.06)`
- stroke-dasharray 计算比例
- 内部显示百分比数字 + 描述文字

## 12. 响应式考量

当前设计锁定宽度 `width=1400`，为桌面端 Dashboard。

| 断点 | 建议 |
|------|------|
| ≥1400px | 当前设计，5列指标 |
| 1200–1400px | 指标卡片改为 4+1 或 3+2 |
| 1024–1200px | 监控区改为 2列 |
| <1024px | 侧边栏收起为图标模式 |
