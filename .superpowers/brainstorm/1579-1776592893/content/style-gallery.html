设计风格画廊

12 种当下流行的设计风格，慢慢看，告诉我你对每种的感觉

不用急着选"最终方案"——看到喜欢的点👍，不喜欢的点👎，不确定就跳过。我会从你的反应里理解你的审美。

Glassmorphism

经典毛玻璃 + 半透明卡片
浮在渐变背景上

1. Glassmorphism 经典
渐变底色 + 白色半透明毛玻璃卡片。最经典的玻璃拟态效果。
参考: iOS/macOS 控制中心, Dribbble 热门

Aurora 极光

暗色底 + 发光色球
神秘、深邃、有氛围

2. Aurora 极光
深色背景上漂浮着柔和的彩色光球，像极光一样。暗色但不沉闷。
参考: Stripe 官网, Linear, macOS 屏保

3. Bento Grid
不等大小的方块网格布局，像日式便当盒。活泼、有节奏感。
参考: Apple 产品页数据展示, Gumroad

Neumorphism

柔和凸起质感
温润、有触感

4. Neumorphism 新拟态
浅灰底 + 内外阴影产生凸起/凹陷效果。像实体按钮一样有触感。
参考: 2020 设计趋势, 概念 UI

Soft Gradient

柔和渐变底 + 轻透卡片

5. Soft Gradient 柔渐变
极淡的多色渐变底 + 轻透毛玻璃卡片。温润、有层次、不刺眼。
参考: Arc Browser, Raycast, macOS Widget

Vaporwave

高饱和粉紫渐变
梦幻、炫酷、有个性

6. Vaporwave 蒸汽波
高饱和粉紫渐变 + 半透明卡片。颜色更浓更炫，有复古未来感。
参考: 蒸汽波美学, 概念设计

7. Swiss Grid 瑞士网格
严格网格 + 红蓝黑三原色 + 大量留白。理性、有序、设计感强。
参考: 瑞士平面设计, Apple Music

Organic Blob

有机形状 + 柔和色彩
自然、亲和、有温度

8. Organic Blob 有机形状
不规则色块 + 柔和渐变 + 毛玻璃卡片。自然流动的曲线，不方方正正。
参考: Stripe, Gumroad, 很多 SaaS 落地页

Cyberpunk

暗色 + 荧光绿 + 扫描线
赛博朋克、硬核科技

9. Cyberpunk 赛博朋克
深黑底 + 荧光绿/品红 + 扫描线效果。硬核科技感，像黑客终端。
参考: 赛博朋克游戏 UI, 终端模拟器

Soft 3D

柔和立体感卡片
有质感、有深度

10. Soft 3D 柔和立体
浅色底 + 多方向阴影产生立体感。比新拟态更现代，像浮起的纸质卡片。
参考: Clarity 设计系统, Apple Card

Material You

Google 动态配色
圆润、统一、个性化

用户 组织 应用
11. Material You
Google 设计语言。大圆角 + 动态配色 + 药丸按钮。圆润亲和。
参考: Android 12+, Google 产品

Tokyo Night

深蓝底 + 柔蓝紫光
深夜主题、护眼、高级

12. Tokyo Night
深蓝灰底 + 柔和蓝紫色调。暗色但优雅，像夜间城市的灯光。开发者最爱。
参考: VS Code Tokyo Night 主题, GitHub Dark
